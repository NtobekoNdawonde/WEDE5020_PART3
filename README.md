README.md – WEDE5020 POE – SEO Discussion

1. Define SEO and explain its purpose in web development.

SEO (Search Engine Optimisation) refers to the process of improving a website so that it can appear more visibly in search engine results such as Google. The main purpose of SEO is to help users find a website more easily when searching for information, products or services. In web development, SEO involves using relevant keywords, organised content, proper HTML structure and descriptive page titles. These techniques help search engines understand what a website offers and connect it with people searching for related information.

2. Explain how SEO practices can improve user experience (UX) and website performance.

SEO practices contribute to a better user experience by making websites easier to navigate, understand and access. A mobile-friendly layout allows users to browse comfortably on different devices, while clear headings and organised navigation help them find information quickly. Website performance can also improve through image optimisation, efficient CSS and JavaScript, and reduced loading times. When a website loads quickly and works properly, visitors are more likely to remain on the site and explore its content.

3. Discuss the benefits of implementing SEO on a website.

Implementing SEO offers several benefits to a website. Firstly, it can increase organic traffic by helping more people discover the website through search engines. Secondly, it improves online visibility and can help a business reach its intended audience. SEO can also build trust because users often consider websites appearing in relevant search results to be useful and credible. Furthermore, effective SEO can support business growth, attract potential customers and reduce the need to depend entirely on paid advertising.

5. Explain the purpose of HTML meta elements and demonstrate relevant examples.

HTML meta elements provide additional information about a webpage. They are placed inside the <head> section of an HTML document and are not normally displayed as visible webpage content. Meta elements help browsers and search engines understand important details about a website. They can provide information such as the page description, author, keywords and viewport settings.

Examples include:

Meta Description:

<meta name="description" content="Discover stylish and affordable sneakers at Sneaker Department.">

This describes the webpage and may appear in search engine results.

Meta Keywords:

<meta name="keywords" content="sneakers, affordable footwear, sneaker collection">

This identifies words associated with the webpage, although major search engines such as Google do not use this tag for ranking.

Meta Viewport:

<meta name="viewport" content="width=device-width, initial-scale=1.0">

This helps websites display correctly on different screen sizes and mobile devices.

Meta Author:

<meta name="author" content="Sneaker Department">

This identifies the author or organisation responsible for the webpage.

Open Graph Meta Tag:

<meta property="og:title" content="Sneaker Department | Home">

This helps control how a webpage title appears when the website is shared on social media.

In conclusion, HTML meta elements provide useful information about webpages, support search engine understanding and improve how website content is presented across different platforms.
